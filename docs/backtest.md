<h1 align="center">Backtest Engine</h1>

This document describes the ladder backtest engine, optimizers, costs, and
benchmarks（当前为 **沪深300 + TopN=30 + 5子账户/持有5天** 版本）。

## Overview

The backtest is fully decoupled from training: it reads saved alpha parquets
(`results/alphas/h{h}/alpha_agg.parquet`) and market data, and runs a staggered
sub-portfolio backtest.

```
saved alpha (T×N) ──> LadderBacktest ──> NAV series + metrics (sharpe/ann/mdd/turnover)
       +                    │
    market data             ├─ optimizer (TopN)
                            ├─ account (stateful holdings)
                            ├─ constraints (limit-up/down, weight cap)
                            ├─ costs (stamp duty + commission)
                            └─ execution (VWAP / close)
```

## Stock Universe

The backtest restricts the stock universe to **CSI 300 constituents**
(`member_mask_csi300.parquet`, point-in-time). Only the `topn` pool is used:
top-N equal-weight from the CSI300 universe each day. **Default N = 30**
(~top 10% of the 300-name universe).

## Simplifications & Limitations

> **This is a simplified backtest for signal validation, not a production-grade
> simulator.** Treat absolute Sharpe/return numbers as indicative; the **relative
> comparison across horizons** is what matters.

- **No slippage / market impact.** Trades fill at the full-day VWAP.
- **Buy and sell share one price.** Both legs fill at the same VWAP.
- **Full-day VWAP only.** No intraday execution windows.
- **Limit-up-blocked buys roll over.** Blocked weight is redirected to substitute
  names (next-highest-alpha names that are tradable and not limit-up).
- **Suspension freezes the position.**
- **Equal-weight, no risk-model constraints.**
- **No turnover control.** Turnover is reported, not constrained.
- **Single-day execution.** Entire target fills in one day at t+1 VWAP.
- **Weight-based, not share-based.** No lot-size rounding, scale-free.
- **Limit up/down is approximated** (see [data.md](data.md)) since `limit_list_d`
  requires 5000 Tushare points.

## LadderBacktest

`engine/ladder_backtest.py` — staggered sub-portfolio backtest.

- Total capital split into **`n_ladders=5`** sub-accounts, each `1/5`.
- Sub-account `k` rebalances on days `[k, k+freq, ...]` with **`rebalance_freq=5`**.
- Each sub-account rebalances every 5 days (matches the target `h=5`); across
  sub-accounts 1/5 of capital rebalances each day → turnover dispersed daily.
- Total NAV = sum of sub-account NAVs.

## Optimizers

`engine/optimizer.py` — stateless pure functions:

- **`TopNOptimizer(n, member_masks=None)`**: top-N alpha names, equal-weighted.
  With `member_masks` (CSI300 daily constituent mask), candidates are restricted
  to the index universe. Used by the backtest with `n=30`.

## Costs

`engine/base/costs.py` — A-share transaction cost model:

- **Stamp duty**: 0.05% (sell orders only).
- **Commission**: 0.025% (both sides).

## Execution & Timeline

- **`DailyClose`**: signal at day `t` close → execute at `t+1`.
- **`VWAPExec`**: execute at next-day post-adjusted VWAP.

## Index Benchmark

`run_backtest.py` computes the **CSI300** buy-and-hold benchmark over the test
period (from `index_close.parquet`).

## Usage

```bash
# Aggregated alpha, top-30 within CSI300 (default)
python scripts/run_backtest.py --mode agg --topn 30

# Specify horizons
python scripts/run_backtest.py --mode agg --topn 30 --h 1 3 5

# Seed mode (backtest each of 15 seed alphas, average metrics)
python scripts/run_backtest.py --mode seed --topn 30 --h 5
```

### Arguments

| Arg | Values | Description |
|---|---|---|
| `--mode` | `agg` / `seed` | `agg`: aggregated alpha; `seed`: per-seed alphas averaged |
| `--topn` | int (default 30) | Number of stocks to hold |
| `--universe` | comma-separated (default `csi300`) | Constituent pool for `topn` |
| `--h` | int list (default 1..5) | Horizons to backtest |
| `--no-rollover` | flag | Disable rolling limit-up-blocked buy weight to substitutes |

## Output

`results/backtest/`:

- `backtest_{mode}_topn_{config}_h{h}.csv` — NAV series per h.
- `backtest_{mode}_topn_summary.csv` — summary (sharpe/ann/mdd/turnover).
- `log_backtest.txt`

`results/figures/backtest_nav.png` — NAV curves (generated by `run_plot.py`).
